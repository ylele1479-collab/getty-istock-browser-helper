Getty / iStock 图片助手 · 2.4

不用启动 EXE、本地服务或 Python。OCR 模型和处理引擎随 ZIP 提供。
适用：电脑上的 Chrome、Microsoft Edge。

2.4.0 速度与导航改进
候选图片改为4路并发读取，某张完成后立即补入下一张，减少等待较慢请求造成的空档。
同一张图片处理期间，完全相同的识别区域与识别参数会复用已有OCR结果，减少重复计算；任务结束即释放，检查失败仍会重新尝试。
减少处理引擎输出时的重复字节拷贝。保留原有对齐、局部修补、水印检查和真实像素门槛。
右下角新增“↓ 回到底部”，位于“↑ 回到顶部”正下方。新增批次后再次点击，会到达当前页面的最新底部。
本版主要提高处理效率，继续查找网页实际提供的最大同素材图源，不以2048作为查找终点。最终像素仍取决于网站提供的文件。
速度对比与验证范围见“2.4更新说明.md”。

2.3.1 解析修复
从已经打开且正常显示的网页记住地区站，优先沿用该站及同照片的真实详情链接，避免固定查询 .com 而丢失高清图源。
指定图片不在搜索页前20张时，仍可按素材编号读取，不需要新开一批素材页。
已经打开的同一详情页直接读取当前文档；同站查询复用正常网页的访问状态，验证页面仍须手动处理。
修复网络超时被当成手动停止的问题，已取得的可用图源不会因此丢失。
只有小图且高清查询被验证拦住时会暂停提示，不再无声地当作解析结果返回。
已找到高清、但局部处理检查未通过时，会在卡片上明确显示高清尺寸及退回原图的原因，仍禁止保存。

2.3.0 试看图
在待解析列表中，把鼠标移到“正常素材页”文字上，左侧会浮出对应原图的试看图，无需先解析。
移开鼠标、滚动列表或按 Esc 会隐藏试看图；键盘聚焦链接也可以查看，点击链接仍正常打开素材页。
看过的图片会缓存；删除或清空列表时释放对应缓存。加载失败或需要验证时会显示提示。

2.2.0 改进
只保留两个对照版本：左边“解析前”，右边“解析后”，放大窗口也只在这两个版本之间切换。
放大窗口的图片区域两侧中央提供左右箭头，点击即可切换这两张图，放大时箭头仍固定可用。
修复放大后再次双击不能还原的问题；双击放大，再次双击还原适应窗口，放大后仍可拖动查看。
找到 2048 图源后仍继续核对网页公布的更大同素材图源，不把 2048 当作查找上限。
实际输出保持取得图源的真实尺寸；网站只提供 2048 时，不能保证输出更大，不使用 AI 重绘或插值放大。

2.1.0 改进
每张卡片顶部显示原链接、批次以及第几张/总张数；处理中、失败、跳过时都保留编号。
修复优先无水印模式遗漏已发现高清图源、过多小图挤掉后出现高清图源的问题。
只有输出水印检查通过、并取得比对照图更多的真实像素时，才允许保存。
未达标结果仍可查看原因和前后对照，但不能通过确认框强行保存。
单张、放大窗口和批量保存统一执行这项规则，批量保存只处理合格图片。

2.0.1 修复
补齐 85 版局部处理所需的原始检查模板，修复部分照片未采用处理结果的问题。
支持繁体“縮放”和简体“缩放”控件读取更大图源。

第一次安装（只做一次）
1. 右键 ZIP → 全部解压。把“Getty-iStock插件”文件夹放到固定位置。
2. 在浏览器地址栏输入 Chrome：chrome://extensions
   Edge：edge://extensions
3. 开启“开发者模式” → “加载已解压的扩展程序”，
   选择里面能看到 manifest.json 的“Getty-iStock插件”文件夹。
4. 右上角拼图图标中，把“Getty / iStock 图片助手”固定到工具栏。
   安装后不要删除或移动这个文件夹。

更新旧插件
关闭旧工作台，用新包里的全部文件覆盖原来加载的插件文件夹，
到扩展管理页点此插件的“刷新”，再点击工具栏图标。
不要只替换某个 JS 文件；新版包含完整处理引擎。
如果另选了新的安装目录，请先停用旧插件，避免同时显示两个图标。

日常使用
保持原来能正常浏览的 Getty / iStock 网页打开，例如香港站搜索页；解析会自动读取该地区站，不必逐张新开网页。
1. 粘贴或拖入链接后，会立即显示识别到几张图片，并可逐张删除。
2. 点“解析并预览”，完成一张显示一张，旧批次预览会继续保留。
3. 看卡片上的水印检查和真实像素是否都通过，再点“保存”或“保存合格图片”。
4. 右下角可使用“回到顶部”和其下方的“回到底部”。

高清从哪里来
沿用 84 / 85 的处理方式：寻找实际较大的同素材图源、真实解码，
使用同素材较小参考图做局部修补，并保留 OCR 参考图和残留水印检查。
不使用简单放大或 AI 重绘来冒充真实高清。
网页没有提供更大图片、参考图不可靠、检查不通过时，会保留原图并说明原因。
首次解析需要加载包内处理引擎，请留意页面状态文字。

取得网页中的高清
先在正常浏览器打开素材页，等图片显示，再点插件图标或“读取已打开的网页”。
更多设置默认允许在已经打开的素材页尝试一次正常放大，读完会尽量关掉本次放大框。
你事先打开的放大框会保留，不会被插件关闭。
解析不会自动新开素材页，也不会自动保存。
遇到验证，手动在正常网页完成，再点击“我已处理，继续”；也可跳过或停止。
可在“图片处理与更多设置”中补充同素材高清图片链接，或关闭局部修补。

对照预览
卡片固定左边“解析前”、右边“解析后”，各显示实际尺寸；解析前使用输入图片或同素材对照图。
点击图片可放大；← / → 或 A / D 切换解析前/后；双击放大，再次双击还原适应窗口，也可点“还原大小”。
放大后可拖动查看；这些预览操作不会改变下载文件的像素。
没有取得更多真实像素、仍是小图、水印未处理成功或检查不确定时，禁止保存。

下载位置
默认保存到浏览器下载目录中的 Getty-iStock 子文件夹。
想固定到自己的目录：展开“下载位置与设置” → “选择并记住目录”。
浏览器可能要求你允许访问所选目录；以后会记住，权限失效时按提示恢复。
“查看所选目录”在插件内列出文件；“打开浏览器下载文件夹”打开浏览器默认下载目录。
纯插件不能直接唤起任意 Windows 路径的文件夹窗口。
重复图片会提醒，不覆盖已有文件；同名但内容不同会另起文件名。

其他保留功能
多链接与补充图源、整页拖入、逐张删除、停止/清空、试用样本、Fetchpik 返回图片，
解析前后对照、前后尺寸、复制原链接、源图信息、固定目录和重复提醒。
Fetchpik 使用方式仍是手动打开其网页，将最终返回的 short.askingtips.com/uploads/ 图片地址粘贴。
