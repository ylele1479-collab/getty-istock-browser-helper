# Getty / iStock 图片助手

Chrome / Microsoft Edge 扩展，读取正常打开的 Getty Images / iStock 网页中的公开图源，查询同素材的较大图片，在工作台进行处理、前后对比与手动保存。发布版本 **2.4.0**。

## 下载完整包

**[下载完整可运行版](https://github.com/ylele1479-collab/getty-istock-browser-helper/releases/latest)**，选择 `Getty-iStock-plugin-v2.4.0.zip`。

完整包包含插件代码、Pyodide/Python 浏览器运行环境、ONNX Runtime Web、RapidOCR、OCR 检测与识别模型、处理引擎及依赖。无需安装本地 Python、EXE 或启动本地服务器。图片网页和图源访问仍需网络。

## 安装

1. 将 ZIP **全部解压**到固定目录，不要在压缩包内直接打开。
2. Chrome 地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的 `Getty-iStock插件` 文件夹。
5. 在浏览器工具栏固定“Getty / iStock 图片助手”。安装后保留该目录。

仓库源码同样包含完整引擎与模型，下载仓库 ZIP 后，加载能看到 `manifest.json` 的目录即可。普通用户优先使用 Releases 完整包。Manifest 声明 Chrome 最低版本 102，建议使用当前稳定版 Chrome/Edge；本次没有重新验证所有旧浏览器版本。

## 主要功能

| 功能 | 说明 |
|---|---|
| 多链接导入 | 粘贴或拖入多个素材链接，立即统计并支持逐项删除 |
| 读取当前网页 | 从正常打开的素材页、搜索页读取公开图源和素材信息 |
| 地区站沿用 | 优先沿用当前已正常访问的 Getty 地区站与同照片详情链接 |
| 同素材高清查找 | 检查网页实际提供的较大图源，不固定在 2048 像素停止 |
| 批量工作台 | 逐张显示结果，保留旧批次，支持停止、跳过和清空 |
| 悬停试看 | 待解析列表中悬停素材页链接可查看原图 |
| 本地处理引擎 | 在浏览器内执行 OCR、同素材参考图对齐及局部处理 |
| 质量检查 | 展示水印检查和真实像素门槛；未通过的结果禁止保存 |
| 前后对照 | 解析前/后双图、尺寸信息、放大、切换与拖动查看 |
| 手动保存 | 单张保存、保存合格图片、固定保存目录和重复提醒 |
| 导航 | 工作台提供回到顶部、回到底部 |

## 日常流程

1. 在正常浏览器打开能访问的 Getty/iStock 网页，等待图片显示。
2. 点击插件图标，或者在工作台使用“读取已打开的网页”。
3. 粘贴链接并检查待解析列表，点击“解析并预览”。
4. 查看每张结果的图源、真实尺寸、处理说明及前后对照。
5. 只有通过检查的结果可以点击“保存”或“保存合格图片”。

首次解析需要载入包内引擎，速度受电脑和图片数量影响。网页出现验证时，需要在正常网页手动完成，再点击继续。扩展不会保证网站一定提供高于 2048 的图片，也不会使用插值放大或 AI 重绘来冒充新增真实细节。

## 下载位置与对比快捷键

默认保存至浏览器下载目录下的 `Getty-iStock` 子目录。展开“下载位置与设置”，可选择并记住另一个目录；浏览器可能要求授予所选目录的写入权限。

点击预览图放大，使用 ←/→ 或 A/D 切换前后版本，双击放大或还原，放大后拖动平移。预览缩放不会改变下载图片的实际像素。

## 随包组件

| 组件 | 用途 |
|---|---|
| Pyodide 0.28.3 | 浏览器内 Python 与 WebAssembly 运行环境 |
| ONNX Runtime Web 1.23.2 | OCR 模型推理 |
| RapidOCR / PP-OCRv6 det、rec ONNX | 检测与识别文本 |
| NumPy / Pillow / OpenCV | 图像解码与处理 |
| `engine/original.zip` | 处理模块和相关原始依赖 |
| `engine/bundle.json` | 引擎文件和来源校验信息 |

当前发布采用已打包的 2.4.0 稳定包，未包含尚未完成的后续 GPU 改造，也不承诺 GPU 加速。详细使用说明见 [先看这里.txt](先看这里.txt)，版本变更见 [2.4更新说明.md](2.4更新说明.md)。

## 限制与故障排查

- 网站未公开较大图源、地区站受限、需要登录或验证时，结果会受网站实际响应影响。
- 高清尺寸和检查通过是独立条件；取得高清但检查失败时仍可能禁止保存。
- 模型和运行环境是本地随包提供；获取网络图片仍依赖可访问的网页与图源。
- 更新插件请替换完整目录、刷新扩展并重新打开工作台，避免只替换单个 JS 文件。
- 该工具是第三方辅助工具，不代表 Getty Images / iStock。图片使用权限由图片本身及网站授权决定。

第三方组件说明及许可证见 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)、`vendor/` 与引擎包中的声明。
